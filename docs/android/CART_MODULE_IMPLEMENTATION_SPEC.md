# 购物车模块完整实现说明（数量/价格修改 + 布局设计）

来源：`wenwen-shop/index.html` 购物车模块。适用于需要复刻、移植或让 AI 修改该模块的场景。

## 一、数据结构

购物车是全局对象 `cartItems`，以商品 id 为 key：

```js
cartItems[productId] = {
  id: productId,      // 商品ID
  name: p.name,       // 商品名
  unit: p.unit,       // 单位
  price: p.price,     // 当前成交单价（可改，初始取商品标价）
  qty: 1,             // 数量
  maxStock: p.stock   // 加入时的库存快照，作为数量上限
}
```

- `addToCart(productId)`：已有该商品则 `qty++`；达到 `maxStock` 时提示「已达库存上限」并中止；没有则新建条目。加完更新悬浮购物车角标，非静默模式弹「已加入购物车」提示。
- `removeFromCart(productId)`：直接删除 `cartItems[productId]` 后重新渲染面板。

## 二、数量 / 价格修改逻辑

### 1. 交互模型

购物车面板由 `renderCartPanel()` 整体重渲染。每个商品卡片下排有：数量输入框、金额输入框、中间 `+/-` 按钮组。

- 两个输入框都是 `type="text"` 且 `readonly`，禁止键盘输入。
- 点击某个输入框后，该框高亮（`.selected`），同时该卡片的 `+/-` 按钮组显示（`.visible`）。
- 同一时刻只有一个字段被选中；切换前清除所有 `.selected` 和 `.visible`。
- 点击面板空白处取消选中（`activeFieldNew = null`）。
- `+/-` 只作用于当前选中字段；未选中时点击无效果。

### 2. 数量修改

- `+`：`newQty = qty + 1`；若 `newQty > maxStock`，提示「已达库存上限」并中止。
- `−`：`newQty = qty - 1`；若 `newQty < 1` 直接返回，最小为 1。
- 写入后同步数量框、小计、底部汇总和悬浮角标。

### 3. 价格修改

- `+`：当前价格每次增加 `0.5` 元。
- `−`：仅当前价格大于 `0.5` 时允许减 `0.5`；下限 `0.5`，无上限。
- 写入后以两位小数显示，并同步小计、汇总和悬浮角标。

### 4. 长按连发

- `+/−` 同时绑定点击和长按。
- 按下 `500ms` 后开始连发，首次触发后按 `200ms` 间隔循环。
- 每次间隔 `speed = max(40, speed × 0.9)`，最快 `40ms/次`。
- 松手、取消、移出按钮时清定时器。
- 长按松手时不得再额外触发一次普通点击。

### 5. 兼容保留更新函数

- `updateCartQty(productId, delta)`：按 `±1` 更新，并校验库存上限。
- `setCartQty`：直接设值，非法或超库存时提示并回滚重渲染。
- `updateCartPrice`：校验 `parseFloat`，负数或 `NaN` 忽略。

### 6. 结算兜底校验

提交前重新拉取最新数据，逐商品校验：

1. 商品是否仍存在。
2. `qty <=` 云端最新 `stock`。

任一商品不满足则整体中止，不扣减任何库存。全部通过后逐条扣库存，并按 `qty × price` 生成销售记录，`unitPrice` 使用购物车修改后的价格；成功后清空购物车。

## 三、整体布局（Bottom Sheet）

- 全屏遮罩 `rgba(0,0,0,0.4)`。
- 底部弹层宽 `100%`、最大 `560px`、高 `95vh`，`0.3s` 从底部滑入。
- 纵向三段：Header → 中间滚动区 → 固定底部汇总区。
- 滚动区和汇总框使用毛玻璃卡片：`rgba(255,255,255,0.62)`、`blur(20px) saturate(1.6)`、圆角 `20px`、细白边框和轻阴影。

## 四、商品卡片

- 宽度撑满滚动区，面板左右 `12px` 边距，body 左右 `14px` 内边距。
- 高度不固定，通常约 `90~100px`。
- 内层卡片内边距 `12px 14px`，圆角 `20px`，白底、细边框、轻阴影，卡片间距 `10px`。

三行内容：

1. 商品名（`15px` 加粗）+ 小计（`16px` 加粗，红色 `#E4393C`）。
2. `商品ID · 库存N · 标价¥xx`（`12px` 灰色，单行省略）。
3. 数量框（宽 `64px`）→ 金额框（宽 `86px`）→ `+/-` 按钮组（默认隐藏）。

字段框：

- 高 `30px`，文字居中，圆角 `15px`，边框 `2px`。
- 选中态蓝色边框和浅蓝光晕。

控制按钮：

- `28×28px` 圆形。
- 按下为蓝底白字并缩放至 `0.92`。

左滑删除：

- 内容层覆盖底层红色圆形删除按钮。
- 内容层最多左移 `-50px`。
- 有方向锁定：横向位移大于纵向位移才触发。
- 松手时超过 `25px` 展开，否则回弹收起。

## 五、底部汇总框

固定于弹层底部，毛玻璃圆角 `20px`，内边距 `10px 14px`。

### 第一块：汇总

- 左侧 `类数`：标签 `10px` 灰色，数值 `20px` 加粗，宽 `42px`。
- 左侧 `件数`：标签 `10px` 灰色，数值 `20px` 加粗，宽 `52px`。
- 中间 `1px` 竖分隔线。
- 右侧 `总金额`：标签 `10px` 灰色，金额 `28px` 特粗红色。
- 实时计算：类数 = 商品种类数；件数 = 所有 `qty` 之和；总金额 = `Σ(qty × price)`。

### 第二块：操作行

- 「售出人」与「支付方式」各占 `flex:1`，圆角 `14px` 边框按钮。
- 支付方式选择「记账」时，在汇总与操作行之间插入浅红记账信息卡片，显示欠账人、电话、居住地、备注、金额和「修改记账详情」按钮。
- 最右「售出」为主色蓝实心按钮。

### 空购物车状态

- body 居中显示空购物车图标和「购物车是空的」。
- footer 整体隐藏。
